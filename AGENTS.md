## Agent skills

### Issue tracker

Issues about the generator live as GitHub issues in this repo; product-wide and cross-repo issues live in the parent. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage labels use the default names: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: this repo's own `GLOSSARY.md` and `docs/adr/`, kept free of You Made It vocabulary. The parent's ADRs that shaped the generator are background reading. See `docs/agents/domain.md`.
